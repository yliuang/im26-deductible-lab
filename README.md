# IM26 Deductible Lab

An interactive teaching exercise on Swiss health-insurance deductible choices.

The website compares deductibles using CARA preferences and a subjective cost distribution. Risk-preference choices use the lottery staircase component of the Preference Survey Module; cost beliefs use an adaptation of bins-and-balls elicitation. The healthcare context and CARA conversion are teaching assumptions, described in the exercise's Methods & sources.

All calculations take place in the browser. Reports and progress files are downloaded to the student's device.

`index.html` is the self-contained website, including Plotly.js and its MIT license. It is generated from the maintained local Deductible Lab source using `build.mjs`.
